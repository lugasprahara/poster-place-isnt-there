SOLMARA is an invented island where the sun sets twice — first behind a far ridge, then again into the sea — and this program paints its vintage travel poster from scratch: banded gradient sky, a bisected sun disc, a striped lighthouse on a rocky point, and a shimmering reflection, with the place's name set in real serif glyph outlines embedded in the code. It is a single dependency-free Node program (stdlib only) that rasterizes at 2048×2048, downsamples for antialiasing, and writes a lean 1024×1024 PNG to /output/entry.png.

## Run it

```sh
node main.ts
```
